# 联网桌面天气时钟

基于 **STM32F407 + FreeRTOS** 的联网桌面天气时钟：ESP32-C3 联网完成 SNTP 授时和天气获取，AHT20 采集室内温湿度，ST7789 彩屏分区显示。

## 功能特性

- 🌐 **联网授时与天气**：ESP32-C3 通过 AT 指令连 Wi-Fi，完成 SNTP 网络授时与天气数据获取
- 🌡️ **温湿度采集**：AHT20（I2C）采集室内温湿度
- 🖥️ **彩屏显示**：ST7789 分区显示时间 / 日期 / 室内外温湿度 / 天气图标
- ⏰ **周期刷新**：定时触发，周期性更新时间和天气

## 硬件平台

| 模块 | 型号 | 接口 |
|---|---|---|
| 主控 | STM32F407VET6 | — |
| 联网模块 | ESP32-C3 | UART（AT 指令） |
| 温湿度传感器 | AHT20 | I2C |
| 显示屏 | ST7789 | SPI + DMA |
| RTOS | FreeRTOS | — |

## 系统架构

三任务 + 双队列 + DMA 刷屏：

| 任务 | 优先级 | 职责 |
|---|---|---|
| init | 9 | 初始化外设、创建队列与任务，完成后自删 |
| ui | 8 | 从 ui_queue 取数据，DMA 刷屏 |
| workqueue | 5 | 处理联网、请求天气等耗时操作 |

- `work_msg_queue`：任务派发队列
- `ui_queue`：显示数据队列，串行化刷屏
- DMA（DMA1 Stream4 + 信号量）搬运显示数据，释放 CPU

## 关键设计

- **裸机 → FreeRTOS 重构**：按职责划分任务，实现前后台解耦
- **UI 队列串行化**：所有刷屏操作先进队列，避免多任务竞争 SPI 外设
- **workqueue 分离耗时操作**：联网、请求等耗时操作移出，不阻塞 UI
- **数据安全**：队列传递的字符串 malloc 复制，防止指针悬空；RTC 读两次防撕裂

## 编译与烧录

1. 使用 Keil MDK5 打开 `mdk/stm32f407.uvprojx`
2. 编译后烧录到 STM32F407 开发板
3. 上电后 ESP32-C3 自动连 Wi-Fi，同步时间并获取天气
